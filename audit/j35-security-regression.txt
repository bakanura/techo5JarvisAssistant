Firewall baseline
-----------------
- IoT -> trusted LAN is default-deny.
- WAN -> Jarvis Show is deny-all; no port forwarding.
- HA -> Show TCP 6053 only.
- Music Assistant -> Show TCP 8928 only when paired/enabled.
- Show -> Dashcast TCP 9555 when streamed dashboard is used.
- Show -> HA TCP 8123/configured port.
- Show -> router DNS/NTP/DHCP.
- SSH 22, routed web 8181, SIP and Direct Brain are opt-in exact-host rules only.
- Native house peer traffic uses TCP 8181 on the same IoT subnet and is authenticated independently.
  Wi-Fi client/AP isolation must therefore remain off if native peer intercom/announcements are used.
